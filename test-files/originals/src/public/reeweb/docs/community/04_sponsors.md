# Sponsors

<a name="introduction"></a>

## Introduction

Reeweb is open source and free to use, with no plans to change that. It's also the result of substantial engineering work — the tool, the documentation, the maintenance — that has to be paid for somehow. Sponsors are how that adds up.

This page covers who currently funds the project, how to sponsor as an individual or company, and what sponsoring actually does.

<a name="primary-funder"></a>

## Primary Funder

Reeweb is built and maintained by [Reepolee](https://www.reepolee.com), the same small software company behind the Reepolee framework. Reepolee underwrites Reeweb's core development time.

<a name="how-to-sponsor"></a>

## How to Sponsor

For individuals and organisations that benefit from Reeweb and want to contribute back financially, the path is GitHub Sponsors:

[github.com/sponsors/reepolee](https://github.com/sponsors/reepolee)

For companies that need invoices, custom contracts, or larger commitments, contact us directly at hello@reepolee.com.

<a name="what-sponsorship-funds"></a>

## What Sponsorship Funds

Three things, roughly in order:

- **Maintenance** — bug fixes, security patches, Bun-version compatibility, dependency upgrades.
- **New features and major work** — the items on [the Roadmap](/reeweb/docs/community/roadmap).
- **Documentation** — keeping these docs current as the tool evolves.

<a name="non-financial-support"></a>

## Non-Financial Support

If sponsorship isn't an option, there are other ways to support the project:

- **Use Reeweb on real projects.**
- **Write about it.** Blog posts, conference talks, tutorial videos.
- **Answer questions in Discussions.**
